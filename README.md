# Arcadelux-en
English language strings for the game Arcadelux, re-written to smell better

## Usage

Paste English2.lng into the *Languages* directory of your main game folder, then select English2 from the general tab in options.

## What/Why?

The game is kinda fun but the text is awful and stinky, so I'm doing something about it to make it les bland and condescending.

> If anybody wants to make edits to the game's English text, they can simply edit English.lng.

\- [Riad](https://forum.audiogames.net/post/990876/#p990876)

At the moment I'm just cutting down on the verbosity and the "no, duh!" nature of a lot of the text, but i may in time even give it some personality.

> Anyway, one ought only to improve the strings themselves, not to rewrite them from scratch, I think.

\- [Riad](https://forum.audiogames.net/post/990876/#p990876)

I am cheerfully ignoring this guidance wherever I see fit. Re-writing them is an improvement in many cases (so long as it doesn't actually change the meaning of the game instructions, which I am careful about). There is little of value here to preserve in its original form. Write your own game text next time if you want to be protective of it.
